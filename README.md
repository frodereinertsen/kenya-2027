# Kenya 2027 — familietur

Reise-brosjyre for en 21-dagers familietur til Kenya sommeren 2027.
Statisk nettside (HTML/CSS), publisert med GitHub Pages.

- `index.html` — offentlig inspirasjonsside (rute + høydepunkter).
- `praktisk.html` — praktisk/budsjett (ulenket, `noindex`).
- `images/` — foto fra Wikimedia Commons, se `images/CREDITS.md` for attribusjon.

Alle priser er omtrentlige og må bekreftes nær booking.
